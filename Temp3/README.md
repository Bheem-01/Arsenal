# Email Template Variation 3

This variation uses a split hero layout with a stronger executive briefing feel, compact meta chips, card-based highlights, and a high-contrast CTA block.

Open `email-template.html` in a browser to preview it.

The template uses assets from `Temp1`. If you want to move this variation into its own folder, copy the image assets into `Temp3` and update the paths from `../Temp1/filename` to `filename`.

Replace `{{userName}}` and `sales@aipl.net` with your own merge tag and RSVP address as needed.
