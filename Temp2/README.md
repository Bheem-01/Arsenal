# Email Template Variation 2

This is the second client presentation option. It uses a dark editorial cover, a compact event summary, a numbered conversation list, and a bright RSVP section.

Open `email-template.html` in a browser to preview it.

The template uses assets from `Temp1`. If this variation is shared independently, copy the three image assets into `Temp2` and change the image paths from `../Temp1/filename` to `filename`.

Replace `{{userName}}` with the merge tag supported by your email platform. Replace the sample content and `sales@aipl.net` as needed.
